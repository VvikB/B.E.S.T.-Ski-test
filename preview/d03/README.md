# B.E.S.T. Academy D0.3 — готовая версия для локального просмотра

Production-сборка, около 1,5 МБ. Без Node.js и без нового большого ZIP. Код этой версии — в том же коммите, `academy-d01/src`; зависимости зафиксированы `package-lock.json`. Ветка сохраняет историческое имя `academy-d02`.

В уже клонированном репозитории обновите эту ветку через `git pull --ff-only`. Если репозитория ещё нет:

```sh
git clone --branch academy-d02 --single-branch https://github.com/VvikB/B.E.S.T.-Ski-test.git
cd B.E.S.T.-Ski-test
```

Из корня репозитория запустите:

```sh
python3 preview/d03/tools/serve_demo.py
```

**Откройте http://127.0.0.1:5173/ski**. Это адрес на вашем Mac/компьютере после запуска команды. Остановить: Ctrl+C. Если 5173 занят: добавьте `--port 5174` и откройте соответствующий адрес. Без Python: установите Python 3 с python.org. В macOS используется `python3`.

Для iPhone используйте тот же локальный сертификат и IP из [HTTPS-инструкции](../../docs/next/01_IPHONE_HTTPS_RU.md), заменив только путь запуска:

```sh
python3 preview/d03/tools/serve_https.py --host 0.0.0.0 --port 5443 --cert "$HOME/.best-academy-tls/demo.pem" --key "$HOME/.best-academy-tls/demo-key.pem"
```

На iPhone: `https://<IP-вашего-Mac>:5443/ski`. Требуется совпадение IP сертификата и адреса, доверие локальному CA и одна доверенная Wi-Fi сеть. После проверки остановите сервер и удалите доверие тестовому CA, как описано в инструкции. Не открывайте порт в интернете: сервер без авторизации.

Проверка целостности: `python3 preview/d03/tools/verify_files.py`.

Из исходников: `cd academy-d01`, `npm ci`, `npm run build`. Результат в dist; `npm run preview` открывает его локально. Для обновления снимка preview/d03 потребуется явная новая сборка и манифест, это не dev-сервер.

Просмотр экранов без запуска: [до/после](../../academy-d01/docs/d03/SCREENSHOTS.md). Публичный HTTPS-сайт не развёрнут: подтверждение отзыва старого Google-ключа пока отсутствует. Публикация статических файлов сборки в GitHub не означает включение публичного сервера или подключение старого ключа.

D0.3 не содержит backend, постоянного прогресса, нового урока, экзаменов и сертификатов. B-01 явно обозначен как методический черновик; доступна техническая демонстрация. Владелец подтвердил запуск D0.2 на iPhone; D0.3 и полный I01–I10 пока физически не проверены.
