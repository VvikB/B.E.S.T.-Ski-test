- В legacy-банке 121 запись и 120 уникальных полных записей. Позиции 60/61 совпадают полностью, обе имеют ID 60. ID 22/47 совпадают по нормализованному русскому тексту, но имеют разные варианты/объяснения. Это отдельный уровень дедупликации внутри данных.

## 3. Карточка нового источника

Поля: source_id, filename и archive/member locator, SHA256, получен от/дата, автор/правообладатель (если подтверждён), название/редакция/язык, вид материала, темы и компетенции, страницы/таймкоды, происхождение, права и evidence reference, разрешённые действия, ограничения, категория персональных данных, методический/безопасностный reviewer, замечания и противоречия, план использования. Статусы прав и достоверности независимы.

**Права:** unknown → internal_analysis_only / permission_requested → licensed_for_specified_use / owner_original_confirmed / prohibited / expired. Разрешение хранить файл не равно разрешению копировать изображение, переводить, менять структуру курса или распространять задания.

**Достоверность:** not_reviewed → source_claim_only → cross_checked → method_approved_for_context; отдельно contradiction_found / safety_hold / outdated. Доступность PDF и известное имя школы не делают инструкцию автоматически подходящей для конкретного упражнения/возраста.

**Использование:** internal_reference; original_design_input с проверкой самостоятельности; publish_text; publish_image; translate; adapt; assessment_use. Разрешение на каждую публикационную операцию имеет scope/срок/территорию/лицензионные требования, если они заданы. Неизвестное значение блокирует копирование.

## 4. Работа с будущими архивами

Сначала manifest без исполнения содержимого: размеры, типы, пути, вложенность, шифрование, лимиты распаковки. Ограничить общий распакованный объём и степень вложенности, запретить traversal/симлинки наружу и макросы/скрипты. Защищённый или повреждённый архив фиксировать как unreadable, не обходить защиту. Для сканов отдельно отмечать OCR confidence и сверять критические фразы с изображением страницы.

Затем точные дубликаты по hash, близкие редакции по метаданным/текстовым фрагментам и независимое предметное сравнение с привязкой к страницам. Оригинал не перезаписывать и не публиковать. В отчёте давать темы, факты и краткие необходимые ссылки, не воспроизводить защищённые таблицы/вопросы/структуру курса.

## 5. Правила самостоятельной разработки

Сначала сформулировать собственную компетенцию и критерий наблюдения, затем написать собственный сценарий/текст и brief изображения. Не сохранять чужую последовательность уроков или систему экзамена заменой нескольких слов. Общие факты проверять по авторитетным источникам, но иллюстрации/сценарии создавать заново. Визуальное сходство с чужими рисунками и использование персонажей с известными правами отдельно проверяются.

Новые каталоги этого этапа — **оригинальные проектные предложения**, созданные по требованиям и выявленным потребностям, без анализа отсутствующих пособий. Это не юридическое заключение об абсолютной уникальности и не подтверждённая методическая программа. Перед публикацией нужны предметное ревью и проверка прав/provenance.
