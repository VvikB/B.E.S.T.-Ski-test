# B.E.S.T. Academy — каталог оригинальных уроков v3

Статус: 40 оригинальных проектных карточек; тексты уроков, задания и практика ещё не методически приняты. Внешние пособия не предоставлены и не использовались для копирования структуры. [Компетенции](BEST_COMPETENCY_MAP_v3.md), [схемы](BEST_VISUAL_BRIEFS_36_v3.md), машинная версия [LESSON_CATALOG.json](LESSON_CATALOG.json).

## Общая модель карточки

Каждый будущий урок имеет 15 блоков из согласуемого продуктового шаблона: цель; аудитория; предпосылки; безопасность; собственное объяснение; иллюстрация; интерактив; демонстрация; практика; ошибки; корректировка; контрольные вопросы; критерии освоения; заметки инструктору; связи. Это авторское ТЗ, не перенос структуры чужого курса. Каталог ниже задаёт учебные цели/зависимости/деятельность и проверяемый результат, но не выдаёт непроверенную технику за готовую инструкцию.

Для каждого урока отдельно публикуются возрастные варианты подачи и локали. Цифровые задания допускают KNOW/LAB; OBS/ASSESS требуют отдельного уполномоченного наблюдения. Указанный prerequisite означает проверку соответствующего допуска, а не автоматическое право на практику после прочтения. Для любой физической задачи инструктор подтверждает условия/экипировку/готовность, автор утверждает способ выполнения. Условный экранный успех не разрешает самостоятельный спуск.

## Самостоятельные маршруты по аудиториям

**Kids Foundation:** L-SAFE01 → L-SAFE02 → L-B01 → L-B02 → L-B04 → L-T01 → L-T03 → L-SAFE04 → L-B03 → L-E01 → L-T02 → L-T05. Все предпосылки проверяются; это первые 12 уроков, не полная детская программа. Короткие цельные действия, совместное участие допущенного взрослого, отсутствие публичного рейтинга. Kids Next добавляет остальные core-компетенции по подтверждённым предпосылкам. Детское оформление не упрощает критерий безопасности.

**Kids Next:** после Foundation оставшиеся 16 core-карточек предлагаются в ветках: SAFE03 → B05/B06 → E02/E03 → E04/E05/E06 → S01…S06; T04/T06 добавляются по предпосылкам. Конкретный порядок внутри веток проверяет граф, инструктор задаёт посильное назначение. Итого детская программа не теряет ни одну из 28 core-компетенций; сложные действия не разблокируются одним возрастом.

**Ski / Teen — «Самостоятельное решение с поддержкой»:** старт SAFE01/02 + T01/T03, затем SAFE03/04; опора B01…B06; контроль E01…E06; планирование S01…S06; рефлексия T02/T04/T05/T06 по prerequisites. Сквозная задача — объяснить свой выбор и своевременно запросить помощь без давления сверстников. Подача без инфантильных образов, приватность и родительское участие по утверждённой политике. Все 28 core-уроков доступны в подходящем темпе, не как единая длинная лекция.

**Ski / Adult — «Понимание, проверка, возвращение»:** входной разговор и evidence прежних навыков → SAFE01/02 + T01/T03; повторная проверка B01…B06; E01…E04; SAFE03 + E05/E06 и S01…S06; SAFE04 + T02/T04/T05/T06. Ситуации посвящены осознанной цели, согласованию индивидуальных ограничений и возвращению после перерыва, а не возрастным стереотипам. Те же 28 core-компетенций имеют иной маршрут/контекст; признание прежних навыков только по принятой процедуре evidence, не по нажатию «я умею».

**Pro — «Наблюдать, преподавать, оценивать ответственно»:** после проверки нужных core-evidence маршрут включает цель/возрастную подачу/коммуникацию (P01/P03/P04), наблюдение/протокол (P02/P06), группу и решения (P05/P09), теорию/практическую рубрику (P07/P08), самостоятельный контент/ревью/разбор (P10/P11/P12), с соблюдением prerequisites. Роли инструктора/экзаменатора и квалификация не выдаются за чтение курса. Для преподавания/аттестации требуется отдельный допуск. Профессиональные материалы не воспроизводят структуру чужой школы.

Обозначения возраста Kids/Teen/Adult являются вариантами программы, а не утверждёнными числовыми юридическими границами. Эти границы и родительский процесс должен принять автор с профильной проверкой.

## Каталог

### L-SAFE01 — Перед началом

- Компетенция: **SAFE1**.
- Цель: Различить готовность и условия допуска.
- Предпосылки: входной допуск и согласованные условия.
- Самостоятельная учебная деятельность: Проверить вымышленную карточку занятия и отметить недостающие условия.
- Критерий приёмки материала/ответа: Названы ограничения; начало задачи не разрешено самим приложением.
- Evidence: KNOW/LAB; физическое OBS и ASSESS отдельно.

### L-SAFE02 — Остановиться и обратиться

- Компетенция: **SAFE2**.
- Цель: Выбрать безопасное прекращение задачи и канал помощи.
- Предпосылки: L-SAFE01.
- Самостоятельная учебная деятельность: Разобрать ситуацию с непониманием сигнала.
- Критерий приёмки материала/ответа: Выбран запрос помощи вместо продолжения без понимания.
- Evidence: KNOW/LAB; физическое OBS и ASSESS отдельно.

### L-SAFE03 — Общее пространство

- Компетенция: **SAFE3**.

- Критерий приёмки материала/ответа: Решение учитывает людей, видимость и заданные правила.
- Evidence: KNOW/LAB; физическое OBS и ASSESS отдельно.

### L-SAFE04 — Границы самостоятельности

- Компетенция: **SAFE4**.

- Критерий приёмки материала/ответа: Нет самостоятельной опасной настройки или медицинского заключения.

- Критерий приёмки материала/ответа: Выбор объяснён проверенными признаками; не по красоте позы.
- Evidence: KNOW/LAB; физическое OBS и ASSESS отдельно.

## Пилотный экземпляр Balance

Первым полностью разрабатывается L-B01 с требуемыми L-SAFE01/02 и понятным входом в L-B02/03. Цель — различить принятые признаки опоры. Поставка включает собственный текст, V01, текстовую альтернативу, задачу выбора с объяснением, демонстрацию с подтверждёнными правами, условия практики и протокол OBS. Все 15 блоков обязательны либо имеют обоснованное автором «не применимо»; отсутствующее видео не маскируется неработающей кнопкой.

Проверка: ученик проходит оригинальное цифровое задание и видит сохранение; инструктор отдельно фиксирует наблюдение. До методического утверждения этот маршрут доступен только как внутренний review, не опубликованное руководство.

## Что не переносится как готовый урок

Не воспроизводятся вопросы чужих экзаменов, таблицы школы, последовательность чужих лекций и изображения. Legacy JSON остаётся источником для сравнительной проверки происхождения и тем; все 121 записи сохраняются в контролируемом staging, но не автоматически включаются в новый банк. Отсутствующие источники и нерешённая методика не подменяются уверенными заявлениями о готовности.
