# B.E.S.T. Academy — технические задания на 36 оригинальных схем v3

Статус: briefs для утверждения, не готовые иллюстрации и не методическая инструкция. Каждая схема создаётся с чистого листа по компетенции; чужие изображения, скриншоты, композиции и узнаваемые фирменные персонажи не используются. [Уроки](BEST_ORIGINAL_LESSON_CATALOG_v3.md), [права](BEST_SOURCE_RIGHTS_REGISTER_v3.md), [машинный каталог](VISUAL_BRIEFS_36.json).

## Общая спецификация для художника и разработчика

Ровно 36 master-схем V01…V36. Для каждой задан основной ракурс: сверху, сбоку или спереди. Дополнительный вид используется только если он снимает неоднозначность; отражение/перекраска не считаются ещё одной оригинальной схемой. Kids/Teen/Adult/Pro-подачи — варианты того же media asset с одной технической истиной, а не искусственное увеличение числа материалов.

Поставка: редактируемый оригинал с описанием авторства/прав, чистый SVG с viewBox (ориентир 1200×900), слои для объектов/траектории/подписей, PNG-превью, alt/long description, словарь переводимых подписей, инструкция состояний и changelog. Основной язык первой проверки — русский; остальные локали не помечаются принятыми до ревью. Текст не превращать в нечитабельные кривые: DOM-подписи/доступная альтернатива должны поддерживать перевод и screen reader.

Система: спокойный светлый фон, контрастные контуры, буквенные/текстовые обозначения наряду с цветом. «Лево/право», направление движения и сторона наблюдения подписаны; носок и пятка различимы. Не обрезать важные части на ширине 320 CSS px. Кнопки и legend доступны с клавиатуры, не только drag. Иконки не заменяют смысл.

Физика: явно «учебное упрощение». Не изображать точные силы, центр масс, скорости, углы или тормозные дистанции без принятого основания. Подписи стрелок указывают, что именно они обозначают. Не смешивать траекторию, взгляд и ориентацию лыжи. Правильность изображения не определяет реальный навык человека.

Для публикации нужны: авторский/provenance check, методическая проверка по конкретному упражнению, safety review, доступность, права и проверка всех используемых локалей. Пока спор Edge и контекст Steering не разрешены, соответствующие схемы остаются review-only. Для каждой схемы ниже alt — стартовый проект, который сверяется с конечным изображением.
