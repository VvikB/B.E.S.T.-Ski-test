# B.E.S.T. Academy — три пространства и детальная структура экранов v3

Статус: проект информационной архитектуры и wireframes, не готовый интерфейс. [Каталог уроков](BEST_ORIGINAL_LESSON_CATALOG_v3.md), [общая архитектура](BEST_PLATFORM_ARCHITECTURE_v3.md).

## Пространства и права

**B.E.S.T. Kids:** простые короткие шаги, понятные подписи и оригинальные нейтральные персонажи, совместная практика/участие представителя по политике, закрытый прогресс без публичного рейтинга. Одно главное действие на экран. Нет открытого поиска детей и контактов посторонних.

**B.E.S.T. Ski:** отдельные варианты Teen и Adult внутри пространства. Самостоятельные объяснения, планирование, упражнения, журнал результатов и помощь. Подросток не считается взрослым из-за выбора темы оформления. Возраст/самостоятельность и представитель проверяются сервером, а не переключателем UI.

**B.E.S.T. Pro:** профессиональное обучение и, по отдельным полномочиям, инструкторская Studio, практика, редакционный процесс. Доступ к Pro-урокам не означает роль экзаменатора и не открывает чужих учеников. Автор/редактор/экзаменатор имеют разные разрешения.

## Основные маршруты

Гость → разрешённый авторский обзор → независимый вход/приглашение → допустимый профиль → Kids/Ski/Pro. Представитель управляет связью/разрешениями через общий кабинет, а не входит под общей детской учётной записью.

Ученик → продолжить назначение → prerequisites и безопасность → урок → интерактив KNOW/LAB → сохранённая обратная связь → отдельная реальная практика и OBS → следующий шаг. Экранное выполнение не закрашивает автоматически всю компетенцию как аттестованную.

Инструктор → разрешённые ученики/группы → цель и условия занятия → назначение/наблюдение → протокол → обсуждённый следующий шаг. Экзаменатор → проверка полномочий → утверждённая рубрика → фиксация оснований → самостоятельный итог практики.

Редактор → оригинальный draft → источники/права → методическая проверка → safety → локализация → предпросмотр → публикация версии. Внутренняя защищённая библиотека не появляется на ученическом маршруте.

## Telegram / Mini App / PWA

Bot: одно актуальное основное меню, приглашение/краткий статус/продолжить/помощь; каждый callback подтверждается, затем проверяется actor, scope и revision. Старый callback не меняет попытку: предлагает актуальное действие. `/start` восстанавливает серверный профиль/попытку. Полезная история не удаляется; устаревшие inline-кнопки деактивируются где позволяет API.

Mini App: серверно проверенное initData, затем тот же профиль и маршруты; нельзя доверять initDataUnsafe. Длинный урок/тест здесь или в PWA. PWA: независимый вход и адаптивные экраны. Офлайн — только разрешённые материалы/оболочка; защищённые источники, персональные результаты и экзаменационные ключи не кэшируются общим service worker.

## Три wireframe-направления

Kids: верхняя строка с профилем/помощью → одна цель → одна крупная схема → одно действие → короткое объяснение → следующий шаг. Нет гонки за очками/скоростью.

Ski: продолжить урок → четыре evidence-индикатора B/E/S/T → текущая практика → история. В уроке безопасность до интерактива, разделы раскрываются порциями. Teen-подача отличается словарём и самостоятельностью, не уровнем допуска.

Pro: рабочий список назначений/учеников → план/наблюдение → прогресс/протокол. Редактор показывает статус прав и конкретную причину запрета публикации, а не одну кнопку «опубликовать всё».

## Дизайн и приёмка

Светлый фон, графитовый текст, глубокий альпийский синий акцент; B/E/S/T с буквами и названиями. Собственная иллюстративная система без случайных иконок/чужих персонажей. Контраст WCAG 2.2 AA проверяется измерением; focus, reflow 320 CSS px, zoom 200%, reduced-motion и touch targets проверяются в прототипах/браузере. Декоративная анимация не обязательна для ответа.

До реализации нужны визуальные прототипы K01/K04/K05, S01/S03/S09, P03/P07/P09 и общий вход. Текстовые wireframes этого документа не объявляются готовым дизайном. Архитектура/визуальное направление/возрастные ограничения утверждаются до массового создания UI.
