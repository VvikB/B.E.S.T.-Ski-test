# B.E.S.T. Academy — модель учебного контента v2

Статус: проект схемы и редакционного процесса. Реальный контент не переписан. [Модель данных](BEST_DATA_MODEL_v2.md), [экзамен](BEST_EXAM_REDESIGN_v2.md), решения D-06/D-07/D-11.

## Сущности и версии

`Program` задаёт аудиторию и цель, `CourseVersion` фиксирует маршрут, `ModuleVersion` — B/E/S/T или библиотеку безопасности, `LessonVersion` — самостоятельный урок. Порядок уроков и prerequisites входят в опубликованную версию курса. Детям, подросткам, взрослым и инструкторам могут назначаться разные программы на общих методических элементах; адаптация подачи не изменяет незаметно технический смысл.

У каждой сущности стабильный UUID, у каждой версии собственный UUID, номер, язык/набор локалей, исходная версия, source references, author/reviewer, timestamps и status. Опубликованная версия неизменяема. Исправление создаёт новую версию; старые попытки и просмотренные назначения продолжают ссылаться на прежнюю. При угрозе безопасности версия отзывается для дальнейшего использования, а историческая запись не исчезает. Решение о переносе активного ученика на новую версию — отдельное событие с объяснением.

## Обязательная структура LessonVersion

| Поле | Содержание и проверка |
|---|---|
| goal | Наблюдаемый результат, без обещания доказанной эффективности |
| audience | Программы/возрастная категория/уровень подготовки |
| prerequisites | Ссылки на необходимые навыки/уроки/условия допуска |
| safety | Условия применения, ограничения, когда остановиться/обратиться к инструктору |
| explanation | Проверенное объяснение, разделённое на короткие блоки |
| illustrations | Версии медиа с alt и проверенными правами |
| interactive | Версия задания, действия, обратная связь, альтернатива с клавиатуры |
| demonstration | Проверенная демонстрация движения; видео с субтитрами/транскриптом при наличии |
| practice | Условия, упражнение, требуемое участие инструктора |
| typical_errors | Структурированные ошибки, а не произвольный словарь переводов |
| corrections | Связи error → безопасная корректировка с контекстом |
| knowledge_checks | Версии формативных заданий |
| mastery_criteria | Чтение, тренировочный результат и наблюдение на склоне разделены |
| instructor_notes | Диагностика, адаптация, ограничения, права на просмотр |
| related_materials | Типизированные ссылки на источники/уроки/медиа |

Дополнительно: оценка длительности как ориентир, компетенции, теги, локаль, статус проверки, версия требований и журнал изменений. Поле не может молча считаться выполненным из-за наличия заголовка. При отсутствии необходимой демонстрации урок остаётся черновиком до поставки материала либо согласованной равнозначной формы; фиктивная кнопка видео не считается реализацией.

Контент хранится в типизированных блоках: paragraph, list, safety_notice, figure, video, interactive_ref, practice_ref, knowledge_check_ref. Rich text проходит allowlist-санитизацию; произвольный исполняемый HTML/JS из редактора не публикуется. Модель перевода отдельна от структуры записи, что устраняет дефект текущего `get_localized` (`bot.py:107,566`).

## Медиакаталог

`MediaAsset` / `MediaVersion`: ID, название, учебная цель, B/E/S/T/безопасность, аудитория, источник, авторство, license ID и подтверждающий документ, язык, версия, mime/размер/checksum, безопасный storage key, alt/long description, transcript/captions, статус методической и безопасностной проверки. Публикация запрещена при неопределённых правах или недостаточной текстовой альтернативе.

Исходник SVG и разрешённое преобразование фиксируются отдельно; SVG очищается от scripts, обработчиков событий и внешних опасных ссылок. Загружаемые файлы проверяются по типу и ограничениям. Личные видео учеников не публикуются как общедоступные учебные активы без отдельного разрешения и политики хранения.

## Публикационный процесс

`draft → method_review → safety_review → translation → ready_for_publication → published → archived`.

`changes_requested` возвращает на доработку с причиной. `withdrawn` — отдельное состояние экстренного запрета использования. Переходы осуществляет сервер, а не смена поля из браузера. Авторизация проверяется на каждой операции. Для одной версии требуются зафиксированные решения методического и безопасностного проверяющего; эти роли может выполнять один уполномоченный автор в малом пилоте только при явном назначении и двух отдельных записях проверки.

Перевод проверяется на смысл и безопасность для каждой публикуемой локали. Изменение источника делает прежние approvals и переводы непригодными для новой версии. Непереведённая локаль не получает фиктивную отметку готовности: либо показывается явно обозначенный согласованный fallback, либо версия недоступна в этой локали. Экзамен не меняет язык незаметно посреди попытки.

## Работа с legacy

Сохранить все 121 экзаменационную запись и все учебные блоки в staging с provenance. Полный дубль `id=60` сохраняется как две импортированные записи с разными occurrence ID, пока автор не примет решение; нельзя скрыто уменьшить исходный материал. Перенос в published требует разметки компетенций/источников, ревью и согласования шкалы. Подробности сверки — [план миграции](BEST_MIGRATION_PLAN_v2.md).

Выявленные риски Edge, Steering, усталости, помощи при травмах и подъёмников — блокирующие замечания для соответствующего материала, а не повод заблокировать любую независимую безопасную часть Balance. Методическая приёмка подтверждается человеком; тесты схемы JSON её не заменяют.
