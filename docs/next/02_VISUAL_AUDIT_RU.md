# Визуальная сверка D0.2 → направление Academy 2.0

Проверено: сохранённые фактические mobile-снимки Kids/Ski/Pro и Motion Lab из academy-d01/docs/d02/media; src/components/Art.tsx и токены src/style.css. Снимки принадлежат D0.2, не новым макетам. Основание: docs/v2/BEST_PRODUCT_VISION_v2.md, раздел «Требования к представлению»; BEST_UX_SCREEN_MAP_v2.md, «Дизайн-система». Пользователь подтвердил направление; сами документы v2 помечены проектными. Отдельного финального Figma/пиксельного эталона в этом пакете нет: точное визуальное совпадение с ним не заявляется.

| Область | Факт D0.2 | Отличие / конкретная работа D0.3 | Приёмка |
|---|---|---|---|
| Альпийская атмосфера | Kids/Ski содержат простые собственные SVG гор/леса; Pro в основном карточки | Более выразительный снежный рельеф, глубина 2–3 планов, ясная сезонная среда. Pro — сдержанный пейзаж в шапке, не за таблицами | Все три пространства узнаваемо alpine; текст не лежит на пёстрой сцене; оригиналы/права в реестре |
| Палитра | Светлый фон, графит/зелёный текст, много оливковых/кремовых поверхностей | Согласовать переход к глубокому синему основному действию из v2; зелёный оставить семантическим акцентом, а не перекрасить всё сразу | Один согласованный набор токенов; контраст обычного текста ≥4.5:1, крупных надписей/индикаторов ≥3:1 по применимому WCAG |
| Оригинальные иллюстрации | Геометрический собственный SVG; доступен без внешних лицензий | Перерисовать горный hero Ski и сцену Kids с иерархией света/снега и масштабом человека. | Mobile | Автотесты Chromium до 320px были успешны; iOS неизвестен | Проверить Safari safe-area, перенос текста/200%, touch и возврат из фона по протоколу I01–I10; исправлять подтверждённые дефекты | Физический протокол владельца + целевая регрессия; axe не заменяет VoiceOver |

Порядок: реальные iPhone-дефекты → одна согласованная проба токенов на Ski → Kids и две иллюстрации → Pro → компоновка Lab. Не заменять функции статичной картинкой. Сравнивать снимки только затронутых экранов; видео нужно только при дефекте движения. Лимит новых raster/webp hero — проектно до 200KB каждый; SVG оптимизировать и не встраивать скрипты. Не обещать производительность без замера. Эстетические изменения и цифры бюджета — предложения для утверждения, не уже внесённые изменения.
