## Решения на утверждение

1. Владелец выполняет локальный iPhone-протокол или предоставляет доступный способ наблюдения; до ответа приёмка устройства открыта.
2. Для D0.3: подтвердить глубокий синий акцент и порядок визуальных работ; приоритет конкретных мобильных дефектов выше косметики.
3. Назначить методического проверяющего и согласовать M01–M06; затем разрешить реализацию/публикацию B-01.
4. Перед P0.2: роли, процедура recovery, сроки хранения/регион, оператор, площадка/стоимость; подтверждение отзыва Google-ключа до внешнего запуска.

## Проверки по экономному регламенту

Сейчас изменён только локальный сервер и добавлен пакет приёмки: целевые Python TLS/path tests + один HTTPS Chromium smoke 3D/SVG, XML-проверка схемы. Полный React E2E/video/ZIP не повторяется: src/dist/package-lock не изменены и подтверждены сравнением с 46a7cb4. Историческая D0.2 регрессия остаётся доказательством прежнего коммита, не новой физической проверки.

Перед D0.3: целевые проверки затронутых UI + общая необходимая регрессия перед выпуском. Перед P0.1: сценарий урока, alternative mode, accessibility, публикационный шлюз. Перед P0.2: обязательные PostgreSQL integration/security/restore/end-to-end; экономия не сокращает проверки безопасности.
