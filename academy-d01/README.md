# B.E.S.T. Academy D0.1

Работающая техническая демонстрация: три визуальных пространства и собственная нейтральная 3D-модель лыжника с двумя лыжами. Это **не методически утверждённая техника**, не учебный релиз и не P0.1. Все профили/группы/наблюдения синтетические.

Проект изолирован в `academy-d01/` репозитория `VvikB/B.E.S.T.-Ski-test`, ветка `academy-d01`. Старый `VvikB/best-exam-bot`, его история, банк и прежние проектные материалы не изменены. Здесь нет копии его credentials или учебного JSON.

## Запуск на компьютере

Нужен Node.js **22.12+** (проверено на 24.22.1) и npm. Не открывайте `index.html` двойным щелчком: приложение должно обслуживаться HTTP-сервером.

```bash
git clone --branch academy-d01 https://github.com/VvikB/B.E.S.T.-Ski-test.git
cd B.E.S.T.-Ski-test/academy-d01
npm ci
npm run dev
```

Откройте адрес, напечатанный Vite (обычно `http://localhost:5173`). Если checkout уже есть, используйте существующую копию, предварительно сохраните свои изменения и переключитесь на `academy-d01`; новый worktree не требуется. При закрытом репозитории войдите в свой GitHub разрешённым способом; токены в код/чат не вставляйте.

Маршруты: `/ski`, `/kids`, `/pro`, `/lab`. По умолчанию открывается Ski. Интерфейс на русском. Пароли/ключи/API/БД для D0.1 не нужны. Внешних моделей, текстур, CDN-шрифтов и запросов к Google/Telegram нет.

Production-сборка локально:

```bash
npm run build
npm run preview
```

Preview обычно открывается на `http://localhost:4173`. Для будущего размещения нужен history fallback на `index.html` для маршрутов SPA. Сам Vite preview — средство проверки, не production-хостинг.

## Открыть на своём iPhone в локальной сети

1. Запустите `npm run dev` на компьютере. Vite слушает локальные сетевые интерфейсы (`0.0.0.0`).
2. Подключите компьютер и телефон к одной разрешённой Wi-Fi сети. Используйте показанный Vite адрес `Network` вашего компьютера, например `http://192.168.x.x:5173/lab`, **не** `localhost` телефона.
3. При необходимости разрешите порт 5173 только в частной локальной сети; не настраивайте публикацию порта в интернет. У разных сетей/изоляции Wi-Fi может быть запрет прямого доступа.
4. В Safari проверьте вращение пальцем, три ракурса, reset, play/pause, timeline/frame step, скорость, A/B и SVG. При слабом устройстве выберите «Экономная» или «SVG».
5. Запишите модель iPhone, версию iOS, результаты и проблемы. **В этой работе физического iPhone не было; его проверка не заявляется.** Локальный HTTP не подтверждает работу Mini App в Telegram: для неё потребуется отдельный разрешённый HTTPS/test bot этап.

Внешнее развёртывание не выполнено: отзыв ранее найденного Google-ключа не подтверждён, а пользователь установил это блокером. Публикация исходников этой отдельной ветки не включает запуск сайта или старых интеграций. D0.1 не имеет аутентификации: используйте только закрытый просмотр с синтетическими данными.

## Что работает

- Kids: собственный SVG-персонаж, задача на различение ракурсов, проверка/повтор/сброс, безопасная локальная подсказка. Ничего никому не отправляется.
- Ski: интерфейсный Balance-маршрут, checklist, карточки B/E/S/T, разбор видов evidence и вход в Lab.
- Pro: выбор синтетической группы/профиля, отдельные заметки по профилям в памяти страницы, checklist плана и проект методической карты.
- Motion Lab: оригинальная процедурная фигура/лыжи, orbit мышью/touch, вращение доступными кнопками, top/side/front orthographic presets, reset, play/pause, timeline 0–240, шаг 1/30 с, 0.25×/0.5×/1×/2×, путь R и A/B.
- A/B: два timestamps одного клипа, общий масштаб/камера, **локальное выравнивание**; перенос rig скрыт и подписан. В режиме сравнения траектория отключена с объяснением. Это не оценка правильности поз.
- R — обозначенное начало rig на условной плоскости, не измеренный центр масс. Линия строится из тех же координат, что и marker.
- Качество Auto/Экономная/Высокая; на узком экране Auto выбирает DPR 1 и менее подробную геометрию. SVG сохраняет управление временем, видами и A/B. Свободная пространственная камера есть только в 3D.
- Нет autoplay; при скрытии документа воспроизведение ставится на паузу. Уважение reduced-motion, keyboard controls, видимый focus, native modal dialogs, mobile navigation.
- WebGL context loss/ошибка сцены включает SVG с честным уведомлением; «3D» повторяет попытку. Движок загружается только при открытии Lab.

## Проверки

```bash
npm run typecheck
npm run test
npm run format:check
npx playwright install chromium ffmpeg
npm run test:e2e
```

На Linux может потребоваться установка системных зависимостей браузера по инструкции Playwright (`npx playwright install --with-deps chromium ffmpeg`). Если системный Chromium уже есть, конфигурация использует `/usr/bin/chromium`; другой путь можно задать `CHROMIUM_PATH`. Иначе используется установленный Playwright Chromium. Запись требует FFmpeg Playwright. В текущем окружении использованы системный Chromium и `/usr/bin/ffmpeg` через отдельный каталог Playwright в `/tmp`.

`test:e2e` сначала собирает production bundle, затем запускает локальный preview на 4173. Освободите этот порт от другого сервера перед тестом. Desktop и мобильный профиль запускаются в **Chromium**; имя iPhone в профиле задаёт viewport/touch/DPR, не ОС Safari. Проверки включают действительный 3D-рендер, camera image changes, touch через CDP, controls, SVG, context loss, keyboard, 320 px, axe и lazy loading. Единичная desktop-запись не дублируется для мобильного профиля, этот сценарий явно skipped.

## Права и границы

Сцена, rig, клип, горы, персонаж Рыжик и SVG-схемы созданы программно в этом проекте; чужие пособия/вопросы/персонажи и персональные данные не импортировались. Лицензии библиотек и Manrope сохранены в [THIRD_PARTY_NOTICES.txt](public/THIRD_PARTY_NOTICES.txt). Структура clip manifest — `src/lab/motion.ts`; флаг `methodicallyApproved` ложен.

Заметки/галочки живут только в памяти открытой страницы и сбрасываются при reload. Backend FastAPI, PostgreSQL, настоящая авторизация/назначения, Telegram Mini App интеграция, длительное хранение, учебный экзамен и документы остаются целевыми функциями; они не притворяются реализованными в D0.1. Переход к P0.1 требует отдельного согласования.
