# Открыть готовую D0.1 без установки Node.js

Архив `BEST_ACADEMY_D01_RUNNABLE.zip` содержит **собранное приложение**, исходники, скриншоты и отчёт. Это рабочая техническая демонстрация, не ZIP с одними планами. Внешнего развёртывания нет.

1. Распакуйте архив и откройте терминал в папке `B.E.S.T.-Academy-D0.1`.
2. Если есть Python 3, запустите:

```bash
python tools/serve_demo.py
```

На macOS/Linux команда может называться `python3`. Откройте `http://127.0.0.1:5173/ski` на компьютере. Не открывайте HTML двойным нажатием: нужен локальный HTTP-сервер для JS-модулей и маршрутов.

Для iPhone в той же частной Wi-Fi сети:

```bash
python tools/serve_demo.py --host 0.0.0.0
```

Откройте на телефоне `http://IP-ВАШЕГО-КОМПЬЮТЕРА:5173/lab` (локальный Wi-Fi IP, не 127.0.0.1). При необходимости разрешите порт 5173 только для частной сети. Не публикуйте порт наружу. Это не production-сервер, в D0.1 нет входа/аутентификации.

Маршруты: `/kids`, `/ski`, `/pro`, `/lab`. Для слабой графики — «Экономная» или «SVG». Модель техническая, не инструкция катания. Физический iPhone разработчиком не проверен.

Если Python не установлен, используйте Node.js 22.12+ и инструкции [README](README.md): `npm ci` и `npm run dev`. Остановка сервера — Ctrl+C.
