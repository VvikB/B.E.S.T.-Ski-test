# B.E.S.T. Academy — отчёт реализации D0.1

Дата: **5 ноября 2026 года, Москва**. Ветка: `academy-d01`, репозиторий `VvikB/B.E.S.T.-Ski-test`, каталог `academy-d01/`.

Результат — runnable React/TypeScript-приложение с тремя страницами и работающим Motion Lab. Оно передаётся на техническую/визуальную приёмку с перечисленными ограничениями. **Приёмка на физическом iPhone и методическая приёмка движения не выполнены.** Это не P0.1, не опубликованный учебный курс и не система выдачи сертификатов.

## 1. Реализация

| Требование | Реализовано | Проверка |
|---|---|---|
| Три пространства | `/kids`, `/ski`, `/pro`; responsive layout, навигация/модальные окна | Production E2E desktop/mobile, реальные screenshots |
| Kids | Оригинальный SVG Рыжик, понятная задача, обратная связь/сброс, локальная помощь | Ответы обоих вариантов, повтор/сброс, help; ничего наружу не отправляется |
| Ski | Balance-checklist, четыре карточки, разные evidence, вход Lab | Checklist/modal/navigation |
| Pro | Синтетические группы/профили, план/методическая карта, раздельные заметки | Смена группы/профиля, сохранение только в памяти и reset после reload |
| 3D skier + 2 skis | Собственная процедурная геометрия, versioned нейтральный клип | Фактический canvas rendering и проверка наличия модели по пикселям |
| Orbit/touch/keyboard | OrbitControls мышью и touch, две кнопки вращения | Изменение изображения; CDP touch input и keyboard Enter |
| Три вида + reset | Orthographic top/side/front, perspective orbit | Четыре различающихся изображения и возврат без SVG fallback |
| Play/Pause/Timeline | 8 секунд, 30 samples/sec, кадры 0–240, scrub | Старт/остановка/границы/стабильность кадра |
| Покадровое управление | −/+ один sample = 1/30 секунды | Unit/E2E, клавиатурный ArrowRight у range |
| Скорость | 0.25×/0.5×/1×/2×; геометрия определяется кадром | Воспроизведение на каждом множителе, детерминированное восстановление pose |
| Траектория | Путь из координат rig marker R; не центр масс | Toggle меняет actual rendered image, mapping общего pose function |
| A/B | Два timestamps одного клипа с общим видом и локальным выравниванием | Захват 30/120, labels, rendering, clear; R-перенос скрыт и обозначен |
| Низкое качество | Low geometry, DPR 1; Auto выбирает low на узком экране | Desktop/mobile DPR-quality state, переключение без потери кадра |
| SVG | Облегчённая условная проекция, виды/время/A/B | Реальное переключение и управление, без ложного утверждения 3D |
| Context loss | Честный fallback и повтор 3D | Синтетическое событие `webglcontextlost`, восстановление |
| Мобильная адаптация | Safe-area, нижняя навигация, controls, 320 px | Chromium mobile viewport/touch, отсутствие horizontal overflow |
| Доступность | Focus, skip link, keyboard, native dialogs, labels, contrast, reduced-motion/no autoplay | Axe на 4 routes × 2 profiles и сценарии keyboard |
| Оригинальность | Свои геометрия/rig/клип/горы/персонаж/схемы, локальный лицензированный Manrope | Исходный код и notices; защищённые пособия не импортировались |

В A/B зафиксированы **статические состояния** A и B. Текущая timeline выбирает момент для нового захвата; это не синхронная анимация двух клипов и не оценка «правильно/неправильно». Кнопки захвата и временные метки показывают состояние явно.

Файлы доказательств: [browser JSON](test-results.json), [desktop axe](accessibility-desktop-chromium.json), [mobile axe](accessibility-mobile-chromium.json), [медиа](media/).

Автоматический axe-проход не означает полного ручного WCAG-аудита. Screen reader на реальных устройствах не проверен.

## 5. Известные ограничения

- **Физический iPhone, Safari/iOS и Telegram WebView не проверены.** Память, sustained FPS, нагрев, батарея, холодная сеть и поведение OS background требуют ручной проверки на устройстве. Автоматика проверяет layout/touch input, не устройство.
- 3D — условная артикулированная фигура с техническим изменением положения, не биомеханическая реконструкция. Видеореференсы и методическое одобрение отсутствуют; не выводятся силы, центр масс, «балл техники» или право на реальное упражнение.
- Low-quality снижает DPR и детализацию, но точный выигрыш на слабом iPhone не измерен. `preserveDrawingBuffer` используется для устойчивого paused render/снимков и имеет дополнительную стоимость памяти, которая ещё не измерена на iPhone.
- 3D vendor chunk около 907 kB raw / 248 kB gzip; Vite предупреждает о размере >500 kB. Он lazy-loaded и не нужен обычным страницам. Это известная оптимизационная граница, не скрытая успешная проверка медленной сети.
- Vite также сообщает об игнорировании library-level `use client` directives при SPA-сборке; это не build failure. SSR не используется.
- Заметки/галочки только в React memory и стираются reload. Нет серверной авторизации, PostgreSQL, долговременного прогресса, реальных групп/допусков, Telegram API/validated initData, installable/offline PWA, экзаменов или сертификатов. Для D0.1 backend был необязателен; целевой стек сохранён.
- «Закрытая демонстрация» — режим использования, не утверждение наличия access-control. В этой версии нет login; не размещать её с реальными данными.
- SVG — облегчённая условная проекция, не свободная 3D-камера и не набор принятых учебных схем. Все 40 карточек и 36 briefs v3 остаются проектными.

После перечисленных исправлений в проверенных сценариях известных критических runtime-дефектов не выявлено. Это ограниченный вывод по выполненным проверкам, не гарантия отсутствия ошибок на непроверенном Safari.

## 6. Безопасность и сохранность

Новый код находится в чистом отчётном репозитории B.E.S.T.-Ski-test, чтобы не переносить credential blob из истории legacy-репозитория. Новые файлы не включают bot token, service-account JSON, исходные пособия или реальные персональные данные. Сеть приложения не обращается к Google/Telegram/внешним CDN.

Репозиторий `best-exam-bot` остался на `ff8000a7f1dfc0bcccd82ad37cf3d0c207101d02`, без tracked/untracked изменений этого этапа. Прежние файлы отчётов и каталоги v2/v3 в B.E.S.T.-Ski-test сохранены. Публикуется отдельная ветка, основная ветка не переписывается.

Отзыв старого Google key владельцем не подтверждён. **Внешнее развёртывание не выполнялось** по установленному пользователем блокеру. GitHub-ветка — исходники/результаты проверки, не запущенный внешний сайт. Локальный просмотр и просмотр с телефона в своей частной Wi-Fi сети описаны в README.

P0.1 не начинался; методические правила, детский production-доступ, практическая аттестация и сертификаты требуют отдельного согласования.
