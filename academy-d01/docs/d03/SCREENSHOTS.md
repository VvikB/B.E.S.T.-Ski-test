# D0.3 — до и после

До: реальные сохранённые снимки D0.2; повторно не создавались. После: production D0.3, Playwright Chromium. Одинаковые CSS viewport: desktop 1440×1080, mobile профиль iPhone 13 390×664 (DPR 3).
