# Обозначения ориентиров D0.2

Короткие подписи уменьшают перекрытие модели; это точки условной геометрии, не анатомические измерения.

| Код | Значение |
|---|---|
| R | Начало модели, не центр масс |
| P | Середина таза |
| C | Плечевой пояс |
| Eᵣ | Правый локоть |
| Kₗ | Левое колено |
| Aₗ | Левый голеностоп |
| Lₛ / Rₛ | Левая / правая лыжа; не маркер R |
| Wᵣ | Правая кисть |

Видимые углы и координаты не означают правильность или безопасность движения. Подписи и вспомогательные линии можно выключать независимо.
